# Colegio Everest knowledge

What the Colegio Everest agent (Javier, a Chrome extension on www.colegioeverest.cl) knows, in
three layers. Every fact is the site's own or from a PDF the school serves; nothing is filled in
from general knowledge. Where two sources disagree (17 vs 15 generations of graduates; María
Ignacia Fuentes vs Josefina Pérez as admissions officer in the vacancies PDF), the files record
which says what. They do not resolve it.

The hand-written layers are in **Spanish**, the site's only language, keeping the site's own names
(Mini Bambolino, Bambolino, Playgroup, Admission Day, Come and Play, Preschool).

**Dated data.** The admission windows, the 2027 vacancies (a PDF uploaded March 2026 that says its
numbers change), the 2026 and 2027 fees and the 2025 casino price are written down as the site and
its PDFs gave them on 2026-10-27, with their year. On that day every published 2027 admission
window had closed; L1 says so.

- **`L1.md`**: always in the prompt. Opens with what the site does **not** say (start times, class
  size, results, open days, admission scholarships, …), then who the school is, the cycles and the
  age rule, admission 2027 (windows, the eight steps, the $45.000 process fee, results, 7 days to
  enrol), vacancies, fees in short, English, formation, sport and facilities, contacts, the CTAs
  (Alexia application, Bookings visit, the Contacto form), the menu and the L2 topics. About 3.5k tokens.
- **`L2/<topic>.md`**: a topic read on demand. The file stem is the topic id; each opens with
  `# Title`, then a `Sources:` line. Hand-written, except `site-map.md` and `noticias.md`, which
  `build.py` generates. Topics: `admision`, `aranceles`, `vacantes`, `ciclos-y-niveles`, `ingles`,
  `formacion-y-pastoral`, `deporte-e-infraestructura`, `vida-escolar`, `historia-y-equipo`,
  `ambientes-seguros`, `documentos`, `noticias`, `site-map`.
- **`L3/`**: generated by `build.py`.
  - `anchors.json`: the **catalogue of places**, `{_meta, header, footer, post, pages: {path: {kind,
    title, header, footer, anchors: [{key, selector, label, hidden?, optional?, positional?,
    href?}]}}}`. Each selector matched exactly one laid-out element on the live page (1440×900),
    or it was dropped and printed. A key is only valid on its own page: GenerateBlocks reuses its
    hash classes across pages. `hidden` places are the adapter's (form fields, the submit, the
    Alexia/Bookings buttons, slider arrows); `optional` = the contact form's answer line, which
    only lays out once used; `positional` = `.entry-content > :nth-child(n)` on paragraph-only pages.
    `header` (menus) and `footer` (address, phone, map, links) apply to every page flagged so;
    `post` is the news-post template.
  - `pages.json`: one record per line, the keys the shared loader reads (`path`, `title`,
    `description`, `sections: [{key, heading, text}]`, `headings`, `text`) plus `kind`, `modified`,
    `documents` and `links` (`{label, url, near, kind}`), `iframes`, `forms` (field names only).
    Pages not to guide to carry `empty: true`. The 40 most recent news posts are pages with
    `kind: "post"` and `date`.
  - `levels.json`: the 17 levels a child can enter in 2027 with the admission page's age rule
    (verbatim) and its window, `born_by` (cut-off 31 March 2027), the `fecha_*` place that shows
    it, the 2027 vacancies and the 2026/2027 fee bands; `fees` holds both fee tables exactly as
    the PDFs write them. The site gives an age only up to Prekínder: `age_if_sequence` (Kínder up)
    is not the site's and must be said as an estimate.
  - `site.json`: the menus (top bar, main menu with dropdowns), the footer, the CTAs that leave
    the site (Alexia application, MS Bookings, Alexia login, upago, Handing, Lirmi, Buk) with
    their URLs, phones, the pages not to guide to, external hosts, REST counts.
  - `documents.json`: every PDF a page links, with its pages and labels, plus three PDFs the
    school serves without a link (Valores 2027, Instructivo Matrícula, Nuevos horarios 2027);
    `note` on the ones that matter, `n_pages`/`bytes` with `--pdfs`. Extracted text stays in the
    local cache.

## Rebuilding

Run from `voqalize/demos`, on a connection the site answers: **colegioeverest.cl refuses India**
(and possibly other countries) — use a US/Chile VPN. Playwright and pypdf are not demos
dependencies, so pull them in for the run (Chromium once with `playwright install chromium`).
The browser is always headless.

```sh
uv run --no-project --with playwright --with pypdf python colegioeverest/backend/knowledge/build.py crawl --pdfs
uv run --no-project --with playwright python colegioeverest/backend/knowledge/build.py crawl --refresh
uv run --no-project --with pypdf python colegioeverest/backend/knowledge/build.py crawl --offline --pdfs
```

`crawl` reads the REST API (pages, posts) and renders every page of the catalogue plus three
recent posts, one at a time, caching each in `~/.cache/voqalize-colegioeverest`
(`$XDG_CACHE_HOME`). A cached page is not rendered again unless `--refresh`; `--offline` rebuilds
from the cache only. Every load waits for `domcontentloaded` (180 s, three tries) with third-party
requests aborted: the server is slow and one stalled tracker held DOMContentLoaded for minutes. No
form is filled or submitted and nothing is pressed. Three refusals (403/405, "Not allowed") in a row
stop the build without writing. After a crawl, check the printed `dropped` lines (a GenerateBlocks
hash changes when the school edits a block), then update L1 and the hand-written L2 if a page changed.

The saved page copies for the extension's page test are in `../../fixtures/` (`fetch.py`).

## Things to know about the site

- **WordPress + GeneratePress + GenerateBlocks.** Full page load on every navigation. The header
  is not fixed. Dropdowns open by adding `sfHover` to `#menu-item-107` (Nuestro Colegio), `-284`
  (Nuestro Modelo Educativo), `-400` (Comunidad Everest).
- **Admission is the main CTA page**, with a long slug:
  `/bienvenidos-al-proceso-de-admision-del-colegio-everest/`. Its "Postulación ONLINE" (Alexia) and
  "Agenda AQUÍ" (MS Bookings) leave the site; both refuse to be framed and ask for personal data:
  open in a new tab, never fill.
- **Contacto is only a Contact Form 7 form** (`#wpcf7-f1250-p1251-o1`: `your-name`, `your-email`,
  `your-subject`, `your-message`, Cloudflare Turnstile, AJAX submit; answer in
  `.wpcf7-response-output`, DOM events `wpcf7mailsent` / `wpcf7invalid` / `wpcf7spam` /
  `wpcf7mailfailed`). The visitor presses Enviar. The denuncias and Trabaja con nosotros forms are
  shown, never filled; the RUT results lookup is unlinked and never filled.
- **Sliders are slick**: the home news carousel (`.slider-noticias`, 9 posts, 3 visible) and the
  Infraestructura gallery (`.slider-for` + `.slider-nav`, 20 photos).
- **Ambientes Seguros**: the per-case protocol tabs sit in an accordion that is `display: none` on
  desktop, so they are not in the catalogue; the four visible stage cards are (`etapa_*`).
- **Site bugs, not repeated**: the admissions e-mail's link opens a different address (use
  mariaignacia.fuentes@colegioeverest.cl); the infirmary's too; "Resultados de admisión 2026" is a
  span, not a link; the Deporte page is empty; the uniform page's Preschool card links the supplies
  list; the 2027 fees, enrolment guide and 2027 timetable PDFs are on the server but unlinked;
  20 linked PDFs answer 404 (19 Conectados guides with accented file names, the COVID protocol),
  marked `status: 404` in `documents.json`. The Evertics page has no `h1.titulo-pagina`.
- **Spanish only**; no English version. A visitor's Chrome may auto-translate the page: prefer
  class- and href-based selectors over text.
