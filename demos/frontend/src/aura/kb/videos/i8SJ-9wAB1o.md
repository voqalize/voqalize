first the **Aura Mobile app** (download → login → MPIN → full
authentication via OTP/Customer ID/DOB/PAN), then **Internet Banking** at
aurabank.example (Login → Register → authenticate via OTP, Debit Card, or Email link
→ set password). Two distinct sub-flows live in one video, so the assistant jumps
to the part the customer asked about.
