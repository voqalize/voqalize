Request a cheque book in a few taps; it's delivered to your registered address.

## Steps
- **Aura Mobile app / Internet Banking:** Services → **Request Chequebook** → confirm
  the account and delivery address.
- Track dispatch in the same section.

> Need to **stop a cheque**? Use Services → Stop Cheque (you'll need the cheque
> number). This is account-specific, so log in first — I can show you where it is.
