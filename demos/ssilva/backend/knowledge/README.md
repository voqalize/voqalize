# SendPotion knowledge

What the SendPotion agent (Javier, in a Chrome extension on sendpotion.com and
blog.sendpotion.com) knows, in three layers. Every fact is the site's own, taken
from sendpotion.com and the Potion Blog on blog.sendpotion.com. Nothing is filled
in from general knowledge. Where the site's own pages disagree, the files record
the disagreement and say which page to quote; they do not resolve it.

- **`L1.md`**: always in the prompt. What Potion is, how it works, features and
  pricing in brief, languages, integrations, security, how to sign up, book a demo
  or get help, the site's navigation, the blog in a line, and the list of L2
  topics. About 2k tokens.
- **`L2/<topic>.md`**: a topic the agent reads on demand. The file stem is the
  topic id. Each file opens with `# Title`, then a `Sources:` line naming the
  pages it was written from. L2 is hand-written from L3, except two generated
  files: `site-map.md` (every page with its exact section headings, tabs and
  widgets, from `L3/pages.json`) and `blog-index.md` (every post grouped by use
  case, from `L3/blog.json` and `blog_notes.json`).
- **`L3/`**: generated by `build.py`, the searchable and highlightable raw material.
  - `pages.json` holds the 27 English pages of sendpotion.com: title, description,
    ordered `sections` (exact heading, level, block, CSS selector, text, items,
    image alts, `reveal`/`tab`/`needs` notes), `faqs`, `pricing`, `cards`,
    `reviews`, `tabs` (with every pane), `forms`/`iframes`, `ctas`, `outbound`
    (links to blog/app with new-tab flag), `stats`, `widgets` and `text`. It keeps
    the Saatvik loader's keys (`path`, `title`, `description`, `headings`,
    `faqs: [{q, a}]`, `text`), so `knowledge.py` can load it unchanged.
  - `blog.json` holds all 145 blog posts: title, subtitle, author, date, reading
    time, tags, headings with their element ids, full text, and the hand-written
    `summary`, `use_cases` and `group`.
  - `site.json` holds the navigation (top nav, language switch, footer), both
    hosts' response headers, fixed elements, globals, the probes (AJAX navigation,
    FAQ open/close, scrolling) and the blog's tag pages.
  The schemas are in `build.py`'s docstring.
- **`blog_notes.json`**: the hand-written summary, use-case keywords and group for
  every post, keyed by path; `build.py` merges it into `L3/blog.json`.

## Rebuilding L3

From `voqalize/demos` (Playwright is not a demos dependency; its Chromium must be
installed once with `uv run --with playwright playwright install chromium`):

    uv run --with playwright python sendpotion/backend/knowledge/build.py crawl            # render what is not cached
    uv run --with playwright python sendpotion/backend/knowledge/build.py crawl --refresh  # re-render everything
    uv run python sendpotion/backend/knowledge/build.py crawl --offline                    # cache only
    uv run python sendpotion/backend/knowledge/build.py search "lip sync"

Rendered extractions are cached in `~/.cache/voqalize-sendpotion` (`site/`,
`blog/`, `meta/`). A full blog crawl takes about ten minutes because posts are
fetched one at a time (Cloudflare rate-limits Medium's custom domain). A rebuild
changes L3 only: a new post appears in `blog.json` with an empty summary and the
build lists it; add its entry to `blog_notes.json`, regenerate `site-map.md` and
`blog-index.md` if pages or posts changed, and update L2 and L1 by hand when new
facts surface.

## Things to know

- **Not Webflow.** sendpotion.com is a custom static site on S3/CloudFront with an
  AJAX router (`pushState` + `#view-main` swap, so the page is never reloaded
  between pages), Smooth Scrollbar on `.pt-layout[data-scrollbar]`
  (`scrollIntoView` does nothing; a `WheelEvent` on `.pt-layout` scrolls) and
  GSAP reveals. No CSP, Permissions-Policy or X-Frame-Options. Tabs
  (`.pt-program-nav[data-program]`), FAQ accordions (`.pt-faq-toggle`, answer
  `display:none` until opened) and "Load more" reviews hide content until
  clicked. There is no form on the site; /demo/ frames Calendly (cross-origin).
  An Intercom launcher sits bottom-right. Probes and headers: `L3/site.json`.
- **The blog is Medium** on a custom domain behind Cloudflare, a client-side app;
  post headings have stable 4-hex ids (`h3#2fcc`), and a reCAPTCHA badge sits
  bottom-right.
- **Brand.** The product is "Potion"; the domain is sendpotion.com.
- **Left out on purpose:** the `/es/` and `/pt-br/` translations; the bodies of
  the privacy policy and terms beyond what `security-and-ai-ethics` summarizes
  (they are in L3); the blog's 207 tag pages (listed in `site.json`, not read).
- **Known disagreements** (recorded in L1 and the topics): 29 vs 30+ languages;
  the $247 "premium plan" in a /reviews/ FAQ vs the /pricing/ plans; the old free
  plan announced on the blog vs today's trials; affiliate 15–30% tiers (blog) vs a
  flat 30% for 12 months (/affiliate/); AI video length up to 5 minutes vs "no
  actual time limit".
