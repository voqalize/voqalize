# Integrations

Sources: https://enveedo.com/ (Supported Integrations), https://enveedo.com/enveedo_platform, https://enveedo.com/partners, https://enveedo.com/book-a-demo, https://enveedo.com/faq.

## Logos shown under "Supported Integrations" (home `integrations`, platform `integrations`, partners `integrations`)
Cloud: Microsoft Azure, AWS, Google Cloud. Endpoint and detection: CrowdStrike, Microsoft Defender, SentinelOne. Vulnerability and code: Snyk, Tenable, Rapid7, Qualys, Faraday. Device management: Microsoft Intune. Identity and workspace: Google Workspace, Okta, Microsoft Entra ID.

## /book-a-demo's list
"Powerful API Integrations with AWS, GCP, Azure, Gusto, Office 365, G Suite, Jira, Okta, with many more in development." "Automated, continuous monitoring across 170+ security controls (CIS, ISO, NIST-CSF, with more to come)."

## How integration works (platform `integration_capabilities`)
Pre-built integrations with leading security tools; an API framework for custom integrations; data import and export; authentication and identity management integration. FAQ: "Yes, Enveedo can seamlessly integrate with a variety of existing security tools and systems … flexible API capabilities."

## Honesty
For a tool not named above (for example ServiceNow, Splunk, Wiz, Palo Alto), say it is not in the published list, that the platform has an API framework and data import, and that the team can confirm in the demo. Never promise a native connector. No public API documentation is published.
