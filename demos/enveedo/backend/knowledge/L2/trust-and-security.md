## Controls (`controls`, `network_security`)
- Network and application security: monthly automated web vulnerability scans; annual external penetration test with a report; SAST and SCA source-code scans; a web application firewall (rules reviewed yearly); an intrusion detection system.
- Governance, risk and compliance: annual SOC 2 Type II audit; annual internal privacy audit; annual security risk assessment on a recognized framework; due diligence on new vendors and an annual vendor assessment; cybersecurity insurance.
- Threat detection and incident response: anomaly detection on infrastructure; a documented incident response plan tested yearly; breach notification mechanisms; email security; endpoint protection.
- Data protection and privacy: TLS encryption between the app and users; regular database backups; customer data deleted within 60 days of termination; yearly regulatory scope analysis and privacy impact assessment; a record of processing activities.
- Access and awareness: role-based access per an access matrix; yearly access review; access removed within one day of termination; security training within thirty days of hire and yearly; monthly simulated phishing.
- Change management: SDLC with approvals; approved infrastructure changes; an SBOM on every merge; application performance monitoring; network security groups.
