# Cannon Home knowledge

What the Cannon Home agent (Javier, in a Chrome extension on cannonhome.cl) knows, in
three layers. Every fact is the site's own; nothing is filled in from general knowledge.
**No layer holds a product price, discount or stock level**: the brain never fetches
cannonhome.cl, and Javier quotes a price only after the extension has read it live on
the page (`product_shown`, `prices_read`, `listing_shown`, `search_suggest`).

- **`L1.md`**: always in the prompt, ~2.2k tokens, hand-written from the crawl and dated:
  who Cannon Home is, the brands, what the menu sells, the size / thread-count / g/m²
  vocabulary, despacho, retiro, cambios, pago, contact, the free-shipping threshold as the
  cart drawer states it (read live in a call), tú, the CLP format ($12.990), and where the
  site contradicts itself.
- **`L2/<topic>.md`**: read on demand (`read_topic`); the file stem is the topic id. Each
  opens with `# Title` and a `Sources:` line. Hand-written: `despacho`,
  `cambios-y-devoluciones`, `medios-de-pago`, `tiendas`, `preguntas-frecuentes`,
  `guia-sabanas`, `guia-toallas`, `guia-plumones-y-almohadas`. Generated by
  `build.py maps`: `site-map` (menu, pages, headings, FAQs) and `catalogo` (per category:
  product types, sizes, colours, materials, hilos, g/m², brands, counts, filters).
- **`L3/`**, built by `build.py` and committed:
  - `products.json` — the 1,750 products `products()` listed on 2026-10-22, one object a
    line inside `[ ]`: `sku, name, path, brand, category, categories, type, size, color,
    material, threads, weight_gsm, attributes, summary, image, family, in_catalogue_at`.
    `family` groups the sizes of one line (rule in `build.py`'s `family_of`).
  - `categories.json` — the category tree (260 nodes), one object a line: `id, path, name,
    parent, level, in_menu, products, filters, quick_filters, options` (the filter groups
    and option labels each listing offers, read from its layered navigation).
  - `pages.json` — 53 pages (policies, FAQ, stores, guides, 17 blog guides, brands, top
    categories): `path, url, type, title, description, h1, sections[{heading, level,
    selector, text, items}], faqs[{q, a, section}]`.
  - `site.json` — crawl date, response headers per page type (CSP enforced, no
    Permissions-Policy), layout probes (fixed header 32 px desktop / 160 px mobile, promo
    bar, WhatsApp button, minicart drawer, mobile sticky add-to-cart bar) and the desktop
    menu tree (`#ninjamenus7`).

## Rebuilding

**cannonhome.cl blocks Indian IP addresses: run the fetching commands through a
non-Indian connection (a VPN).** A 403/405 on an HTML page, a timeout or "Not allowed"
means the connection is blocked; `build.py` stops with `STOP: …` rather than retrying.
Requests are paced to at most two a second. Every response is cached in
`~/.cache/voqalize-cannonhome`, so `--offline` rebuilds need no network.

Run from `voqalize/demos`. Playwright is not a demos dependency; install its Chromium
once with `uv run --with playwright playwright install chromium`.

```sh
uv run --with playwright python cannonhome/backend/knowledge/build.py crawl            # info pages + probes (L3/pages.json, site.json)
uv run --with playwright python cannonhome/backend/knowledge/build.py crawl --refresh  # re-render everything
uv run --with playwright python cannonhome/backend/knowledge/build.py crawl --only /preguntas-frecuentes
uv run python cannonhome/backend/knowledge/build.py crawl --offline                    # rebuild from the cache
uv run python cannonhome/backend/knowledge/build.py catalogue                          # POST /graphql + category filters (~20 min)
uv run python cannonhome/backend/knowledge/build.py catalogue --refresh
uv run python cannonhome/backend/knowledge/build.py maps                               # L2/site-map.md, L2/catalogo.md
uv run python cannonhome/backend/knowledge/build.py search "sabanas king 300 hilos"
```

Nothing here logs in, submits a form or touches the cart; the crawl's browser aborts
every non-GET request except `/graphql`. After a rebuild, re-read `L1.md` and the
hand-written L2 topics against the new crawl (policies, stores and the free-shipping
threshold change).
