# Convenios: Fonasa, isapres, cajas, aseguradoras y otros

Sources: https://www.unosalud.cl/convenio/ y /categoria-convenio/* (titulares de cada tarjeta). Las páginas de detalle de cada convenio (/convenio/<nombre>/) no se pudieron leer: para condiciones, abre la página del convenio.

- Fonasa: "Hasta 50% dcto si eres afiliado a Fonasa".
- Isapres: Cruz Blanca 60%, Vida Tres 60%, Consalud 60%, Nueva Masvida 60%, Banmédica 60%, Colmena "hasta 70% dcto si eres afiliado a isapre Colmena".
- Cajas de compensación: La Araucana "Hasta 70% dcto para todos los afiliados", Caja Los Andes 60%, Los Héroes 60%, Caja 18 60%.
- Aseguradoras: Vida Security 60%, Confuturo 53%, Vida Cámara 60%, BCI Seguros 60%, Bupa Seguros 60%, Consorcio 60%, Zurich 60%, Bice Vida 60%, MetLife 60%, Sura 60%, Help Seguros 60%.
- Cooperativas: Coopeuch 60%.
- Otros beneficios: Banco Falabella ("Beneficios dentales por ser cliente Banco Falabella"), Tarjeta UniónSalud 60%.
- PAD: convenio vigente con Cruz Blanca y Nueva Más Vida.
- Seguro complementario: reciben todos los seguros; beneficios especiales para Sura, Metlife, BiceVida y VidaCámara.
- Los Planes Sonrisa Protegida no son acumulables con otros convenios, descuentos o promociones (salvo campañas específicas para beneficiarios).
- Empresas: el Convenio Empresas ofrece "Planes desde $965 mensuales por colaborador" (/landing/convenio-empresa/).
