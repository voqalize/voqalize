Voqalize runs the voice stack — WebRTC, voice activity detection, speech-to-text,
text-to-speech, interruption handling, recording. You write the **brain**: an
agent that receives text and speaks text back. Your code never touches audio.

## What is a Voqalize app?

A brain is a single WebSocket URL. Voqalize dials `{brain_url}/s/{session_id}`,
one connection per session, opened when a call starts and torn down when it ends.
Where that URL points is up to you — your own inbound server, or a Cortex relay
for brains that can't accept inbound connections. Same brain code either way;
you only choose who dials whom. See [Where the brain runs](/docs/deploy/brain-url/).
