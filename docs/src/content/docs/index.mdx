Voqalize runs the voice stack — WebRTC, voice activity detection, speech-to-text,
text-to-speech, interruption handling, recording. You write the **brain**: an
agent that receives the caller's words and drives two channels back — **speech**,
and **actions** that drive the screen the caller is looking at. Your code never
touches audio.

:::caution[The pages that teach the brain surface are not written yet]
The Python callback surface is being revised, and no page here documents it. The
[SDK README](https://github.com/voqalize/voqalize/tree/main/sdk/python) and the
runnable brains under
[`sdk/python/examples/`](https://github.com/voqalize/voqalize/tree/main/sdk/python/examples)
are the working reference until it settles. Everything else on this site
describes surfaces that have shipped.
:::

## What is a Voqalize app?

A brain is a single WebSocket URL. Voqalize dials `{brain_url}?session_id={session_id}`,
one connection per session, opened when a call starts and torn down when it ends.
Where that URL points is up to you — your own inbound server, or a Cortex relay
for brains that can't accept inbound connections. Same brain code either way;
you only choose who dials whom. See [Where the brain runs](/docs/deploy/brain-url/).
