# stage_shop: Stage in a developer's own app

A small shop page and its brain, on Stage. The agent talks about the sheets
and the page moves with its words: `{show: Our sheets}` scrolls to the
sheets and rings them, `{filter: Size | King}` rings the King option and
presses it, and adding to the cart waits for the visitor's yes.

Nothing here is published yet: `voqalize.sdk.stage` and `@voqalize/stage` are
released together once they have been proved on our own sites.

| File | What it is |
|---|---|
| `scene.json` | The Stage Spec: one move of its own (`core.show`) and two taken from the `commerce` kit. The one place a move is declared. |
| `stage_gen.py` | The brain's moves, generated: `voqalize stage gen examples/stage_shop/scene.json --py examples/stage_shop/stage_gen.py --json examples/stage_shop/scene.page.json`, from `sdk/python`. |
| `scene.page.json` | The page's spec, generated by the same command: the kit merged in, and none of what only the brain reads. |
| `brain.py` | The brain: its replies pass through `Stage.cued`, the page's results and events come back through `Stage.handle`, and `read_screen` answers from the mirror. |
| `index.html` | The page: `data-stage-*` attributes name what the agent may point at and press, and one `attach` call binds them. `commerce.cart_add` is the page's own performer, because only the app knows what adding to its cart means. |

## How the page is marked up

- `data-stage-thing="sheets" data-stage-label="Our sheets"`: something the agent
  can point at, by the words the visitor sees.
- `data-stage-part="Size:King"`: one option a filter presses.
- `data-stage-place="catalog"`: where the page is.

The attributes are locators only. The moves come from the spec, never from the
markup.

## In React

`@voqalize/stage/react` gives the same wiring as hooks, with the app's own React
handed in:

```tsx
import * as React from "react";
import { stageHooks } from "@voqalize/stage/react";
import { scene } from "./stage/scene.gen"; // voqalize stage gen … --ts

const { useStage, useMove, useSlice, useNavigated } = stageHooks(React);
```

`useStage(client, scene)` attaches to the app's pipecat client, `useMove`
registers a performer, `useSlice` turns a state change into the event the spec
declares (the agent's own changes are reported as the agent's), and
`useNavigated` tells the agent about a route change.

Both halves are tested: `sdk/python/tests/unit/stage/test_example.py` keeps the
generated files current and the brain importable, and
`sdk/js/stage/test/example.test.ts` makes this page's cues on its own markup
under the Stage conformance checks.
